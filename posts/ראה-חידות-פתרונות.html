ראה: חידות + פתרונות

01.08.2026

מבחן אמריקאי

  1. מה קרה בהר עיבל?
    1. אברהם בנה מזבח
    2. העם הגרגשי התבצר בו
    3. מעמד הקללה
    4. ההר נפל על ראש עוג מלך הבשן
  2. הביטוי "עם סגולה" מופיע בפרשה. מה כוונתו?
    1. אות מנוקדת עם סֶגוֹל (כמו האות הראשונה במילה מֶלַח)
    2. עם יקר כמו אוצר
    3. קבוצת טרוריסטית שמסוגלת לבצע כל דבר
    4. בית הספר "סגולה" בבני ברק
  3. הביטוי "איש כל הישר בעיניו" מופיע בפרשה. מה כוונתו?
    1. כל אחד עושה מה שהוא רוצה
    2. כל אחד מאמין למי שהוא רוצה
    3. אדם שמחשיב את עצמו לאיש ישר
    4. אדם בעל ראיה דּוּ מְמַדִּית שרואה את הכול שטוח
  4. הביטוי "ובערת הרע מקרבך" מופיע בפרשה. מה כוונתו?
    1. תחזור בתשובה כדי שיצא ממך כל הרוע
    2. אל תשהה את נְקָבֶיךָ בְּקִרְבְּךָ (זה לא בריא) 
    3. שרוף את החמץ לפני פסח
    4. תעקור את החוטאים מהעם
  5. הביטוי "מסית ומדיח" מופיע בפרשה. מה כוונתו?
    1. אדם שמפתה אותך לעבוד עבודה זרה
    2. אדם שמעסיק עובד זר
    3. מכונה משופרת להדחת כלים
    4. מישהו שמנסה להסיט אותך מהכביש
  6. הביטוי "ישמעו ויראון" מופיע בפרשה. מה כוונתו?
    1. כינוי לאנשים בעלי שמיעה וראייה מפותחים
    2. ישמעו את מה שקרה, ויפחדו
    3. סלוגן של מכון לעזרי ראיה ושמיעה
    4. השמועה על מה שאירע בקיבוץ יִרְאוֹן (בגליל העליון)
  7. הביטוי "שסעת שסע" מופיע בפרשה. מה כוונתו?
    1. תינוקת שנולדה עם שפה שסועה
    2. זהו כינוי לתקשורת המשסעת את העם
    3. חצאית שאינה צנועה דייה
    4. בהמה בעלת פרסה חצויה
