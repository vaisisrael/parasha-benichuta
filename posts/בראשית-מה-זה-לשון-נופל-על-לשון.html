בראשית: מה זה לשון נופל על לשון?

15.10.2025

הגייה דומה - משמעות שונה

לְזֹאת יִקָּרֵא אִשָּׁה כִּי מֵאִישׁ לֻקֳחָה

"לשון נופל על לשון" הנה צורת ביטוי נפוצה בשפה העברית, המכילה מילים סמוכות בעלות צליל דומה ופירוש שונה. להלן יוצגו דוגמאות מרתקות לתופעה זו:

במקורות

  1. "לְזֹאת יִקָּרֵא אִשָּׁה כִּי מֵאִישׁ לֻקֳחָה" (ספר בראשית)
    כשם שהנקבה נבראה מגוף הזכר, כך המילה אשה מבוססת על המילה איש.
  2. "וַיִּהְיוּ שְׁנֵיהֶם עֲרוּמִּים הָאָדָם וְאִשְׁתּוֹ... וְהַנָּחָשׁ הָיָה עָרוּם מִכֹּל (ספר בראשית)
    ערומים = מחוסרי בגדים. ערום = חכם וערמומי.
  3. "הוּא יְשׁוּפְךָ רֹאשׁ וְאַתָּה תְּשׁוּפֶנּוּ עָקֵב (ספר בראשית)
    ישופך = לשון כתיתה, דריכה  ושיוף. תשופנו = נשיפה - שריקת הנחש.
  4. "ונח מצא חן בעיני ה'" (ספר בראשית)
  5. "וַיֶּעְתַּר יִצְחָק לַה'... וַיֵּעָתֶר לוֹ ה'" (ספר בראשית)
    הראשון = תפילה והפצרה. השני = הסכמה.
  6. "אֶת בְּכֹרָתִי לָקָח וְהִנֵּה עַתָּה לָקַח בִּרְכָתִי" (ספר בראשית)
  7. "וַיֵּט אהלה מֵהָלְאָה לְמִגְדַּל עֵדֶר" (ספר בראשית)
  8. "וַתִּכְלֶינָה שֶׁבַע שְׁנֵי הַשָּׂבָע אֲשֶׁר הָיָה בְּאֶרֶץ מִצְרָיִם; וַתְּחִלֶּינָה שֶׁבַע שְׁנֵי הָרָעָב" (ספר בראשית)
    הראשון = סיום. השני = התחלה.
  9. "צָרַעַת פֹּרַחַת הִוא בְּקָרַחְתּוֹ אוֹ בְגַבַּחְתּוֹ" (ספר ויקרא)
    קרחת = מאמצע הקודקוד ולאחור. גבחת = מאמצע הקודקוד ולפנים.
  10. "וַיַּעַשׂ מֹשֶׁה נְחַשׁ נְחֹשֶׁת" (ספר במדבר)
  11. "פָרָה אֲדֻמָּה... אֲשֶׁר לֹא עָלָה עָלֶיהָ עֹל" (ספר במדבר).
    3 מילים ברצף!
  12. "וְכִי יָמוּת מֵת עָלָיו בְּפֶתַע פִּתְאֹם" (ספר במדבר)
    בפתע = אירוע אונס. פתאום = אירוע שוגג
  13. "אֶל הַקֻּבָּה וַיִּדְקֹר... אֶת הָאִשָּׁה אֶל קֳבָתָהּ" (ספר במדבר)
    הקבה = האהל, קבתה = הקֵבָה שלה.
  14. "גָּד גְּדוּד יְגוּדֶנּוּ" (ספר דברים)
    3 מילים ברצף!
    גד = שם השבט. גדוד = יחידה צבאית. יגודנו = ימשוך ממנו (משבט גד יימשכו גדודי צבא)
  15. "דָּן יָדִין" (ספר דברים)
  16. "וַיַּעֲשׂוּ אֶת... בָּעֶרֶב בְּעַרְבוֹת יְרִיחוֹ; וַיֹּאכְלוּ מֵעֲבוּר הָאָרֶץ (ספר יהושע)
    3 מילים ברצף!
    בערב = בסוף היום. בערבות = אזור עם צמחיה דלילה. עבור = תבואה.
  17. "וַיַּקְדִּשׁוּ אֶת קֶדֶשׁ בַּגָּלִיל בְּהַר נַפְתָּלִי" (ספר יהושע)
    ויקדישו = הזמינו - ייחדו את העיר לצורך מסוים. קדש = שם העיר.
  18. "וַיִּקַּח יְהוֹשֻׁעַ אֶת עָכָן... וַיַּעֲלוּ אֹתָם עֵמֶק עָכוֹר; וַיֹּאמֶר יְהוֹשֻׁעַ מֶה עֲכַרְתָּנוּ" (ספר יהושע)
    3 מילים ברצף!
    עכן = שם האיש. עכור - שם העמק - הבקעה. עכרתנו = לכלכת אותנו.
  19. "רֹכְבִים עַל שְׁלֹשִׁים עֲיָרִים וּשְׁלֹשִׁים עֲיָרִים לָהֶם לָהֶם יִקְרְאוּ חַוֹּת יָאִיר" (ספר שופטים)
    3 מילים ברצף!
    עַֽיִר = בן חמור. עִיר = ישוב. יאיר = שם האדם.
  20. "וַיֹּאמֶר שִׁמְשׁוֹן בִּלְחִי הַחֲמוֹר חֲמוֹר חֲמֹרָתָיִם" (ספר שופטים)
    3 מילים ברצף!
    החמור = שם הבהמה. חמור = אספתי וערמתי. חמרתים = ערמות.
  21. "כִּי כִשְׁמוֹ כֶּן הוּא נָבָל שְׁמוֹ וּנְבָלָה עִמּוֹ" (ספר שמואל)
    נבל = שם האיש. נבלה = מעשה מושחת.
  22. "הָעִזוּ בְּנֵי בִנְיָמִן מִקֶּרֶב יְרוּשָׁלִַם וּבִתְקוֹעַ תִּקְעוּ שׁוֹפָר" (ספר ירמיהו)
    תקוע = שם העיר. תקעו = השמיעו קול בשופר.
  23. "כִּי מִקְּטַנָּם וְעַד גְּדוֹלָם כֻּלּוֹ בּוֹצֵעַ בָּצַע" (ספר ירמיהו)
    בוצע = גוזל. בצע = כסף.
  24. "אִם תֹּאבוּ וּשְׁמַעְתֶּם טוּב הָאָרֶץ תֹּאכֵלוּ; וְאִם תְּמָאֲנוּ וּמְרִיתֶם חֶרֶב תְּאֻכְּלוּ" (ספר ישעיהו)
    הראשון = אכילה. השני = השמדה.
  25. "שָׂרַיִךְ סוֹרְרִים" (ספר ישעיהו)
  26. "מִן הַפַּח אֶל הַפַּחַת" (ספר ישעיהו)
    פח = מלכודת. פחת = בור.
  27. "וַיְקַו לְמִשְׁפָּט וְהִנֵּה מִשְׂפָּח" (ספר ישעיהו)
    משפט = דין צדק. משפח - סיפוח חטאים זה על זה.
  28. "כִּי כָל סְאוֹן סֹאֵן" (ספר ישעיהו)
    סאון = אסון. סואן = מרעיש.
  29. "בּוּקָה וּמְבוּקָה וּמְבֻלָּקָה" (ספר נחום)
    3 מילים ברצף!
    בוקה = דבר ריק. מבוקה = דבר מלא שהתרוקן. מבלקה = דבר שהושחת.
  30. "וַיִּירְשׁוּ אֶת הָאָרֶץ וַתַּכְנַע לִפְנֵיהֶם אֶת יֹשְׁבֵי הָאָרֶץ הַכְּנַעֲנִים" (ספר נחמיה)
  31. "מַדּוּעַ מָצָאתִי חֵן בְּעֵינֶיךָ לְהַכִּירֵנִי וְאָנֹכִי נׇכְרִיָּה" (מגילת רות)
    הראשון = קירבה. השני =ריחוק.
    "יְשַׁלֵּם ה' פׇּעֳלֵךְ וּתְהִי מַשְׂכֻּרְתֵּךְ שְׁלֵמָה" (מגילת רות)
    ישלם = ייתן תשלום. שלמה = ללא חוסר.

בלשון חכמים

  1. "דְּבַשׁ וְהִדְבִּישׁ" (בבא מציעא)
    דבש = מהדבורה. הדביש = התקלקל (המילה מיוחדת לקלקול דבש).
  2. "אָמְרוּ: לֹא זָזוּ מִשָּׁם עַד שֶׁנְּשָׁכוֹ נָחָשׁ וָמֵת" (שבועות)
  3. "צִיּוֹן הַמְּצֻיֶּנֶת" (פיוט הושענות לחג סוכות)
  4. "הוֹשַׁעְנָא יֶקֶב מִיֶּלֶק" (פיוט הושענות)
    יקב = מקום עשיית יין. ילק = סוג של ארבה המזיק לחקלאות

בספרות

  1. אמרה צפרדע: לא אגור עם עגור, כי אגור מפני עגור. אשר באין לו מלאי אגור - צפרדעים בולע (חנניה רייכמן)
    הראשון = להתגורר. השני = שם העוף. השלישי = לשון פחד. הרביעי = לשון צבירה.
    ואפשר להוסיף בסיום "צפרדעים בולע בערגה"
  2. שׇׁלָּמָה שִׁלְּמָהּ שְׁלֹמֹה שַׂלְמָה שְׁלֵמָה?
    שְׁלֹמֹה שקרע את שמלת חברו, חויב בדין לשלם שמלה שלימה תמורתה.
    הוא כועס ותוהה:
    שׇׁלָּמָה = בשל מה (למה)
    שִׁלְּמָהּ = שילם אותה
    שְׁלֹמֹה = זה שמו
    שַׂלְמָה = בגד 
    שְׁלֵמָה = מחיר מלא
  3. אִשָּׁה נַעֲלָה, נָעֲלָה נַעֲלָהּ, נָעֲלָה אֶת הַדֶּלֶת בִּפְנֵי בַּעֲלָהּ
    האשה החשובה (נַעלה)
    לבשה (נָעלה)
    את הנעל שלה (נעלהּ)
    וגם סגרה (נעלה את הדלת...).
  4. אֵין לוֹ פְּרוּטָה לְפוֹרְטָהּ
    אין לו אפילו מטבע קטנה (פרוטה) שיוכל לפרוט
  5. כלב אסור (קשור) – מותר (להחזיק). כלב מותר – אסור.

לסיום

להלן קטע תלמודי ובו 'משחק מילים' שמזכיר 'לשון נופל על לשון'.
נסו לקרוא את הכתוב:
"תרנגול למי מותר למכור לו תרנגול לבן תרנגול לבן למי אסור למכור לו תרנגול לבן"

וזה פירושו: הקטע דן בהלכות המחייבות אותנו להתרחק מעבודה זרה. בימיהם, היו הנכרים נוהגים להקריב תרנגולים לבנים ביום חג אלילם. ולכן:

  • אם הגוי שואל "תרנגול למי" (למי יש למכור לי תרנגול) - אז "מותר למכור לו תרנגול לבן" (כי אין הכרח שהוא מעונין בו כקרבן לאליל - שהרי לא הזכיר את הצבע 'לבן').
  • אבל אם הגוי שואל בפירוט "תרנגול לבן למי" - אז "אסור למכור לו תרנגול לבן".
